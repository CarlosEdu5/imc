# Calculadora de IMC

Este é um projeto simples de calculadora de IMC (Índice de Massa Corporal) em HTML, CSS e JavaScript.

## Funcionalidades

- Recebe altura em centímetros e peso em quilogramas
- Calcula o IMC usando a fórmula `peso / (altura * altura)`
- Exibe o valor do IMC com duas casas decimais
- Mostra a classificação de acordo com o resultado

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Digite sua altura em centímetros.
3. Digite seu peso em quilogramas.
4. Clique no botão "Calcular IMC".
5. O resultado e a classificação aparecerão na tela.

## Estrutura do projeto

- `index.html` - marcação da calculadora
- `style.css` - estilos visuais
- `script.js` - lógica de cálculo do IMC

## Observações

- O campo de altura aceita valores com vírgula ou ponto decimal.
- O projeto é um exemplo didático e não substitui orientação profissional de saúde.
